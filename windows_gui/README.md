# PKBM Windows GUI 改进版

## 🆕 新功能特性

### 1. 图片功能支持
- 支持为条目添加图片附件
- 自动调整图片大小以适应界面
- 图片存储在 `data/attachments/` 目录
- 支持常见图片格式：JPG、PNG、GIF、BMP、TIFF、WebP

### 2. 书籍信息管理
- 专门的书籍信息字段：作者、ISBN、出版社、页数、评分
- 适合管理读书笔记和书籍摘要
- 分类为"书籍摘要"时自动显示书籍信息区域

### 3. 导出功能
- **单个条目导出**：支持TXT和PDF格式
- **批量导出**：可导出所有条目或按分类导出
- **导出选项**：可选择是否包含元数据、图片信息
- **文件格式**：
  - TXT：纯文本格式，兼容性好
  - PDF：专业文档格式，支持图片和格式化

### 4. 数据库改进
- 自动数据库版本管理
- 向后兼容，自动升级现有数据库
- 新增字段不影响现有数据

### 5. 后端管理功能
- **启动/停止后端服务**：管理Go后端进程
- **连接状态监控**：实时检查后端服务状态
- **数据同步**：与后端API同步数据
- **系统监控**：显示CPU、内存使用情况
- **进程管理**：自动查找和管理后端进程

## 🚀 安装和运行

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行程序
```bash
python main.py
```

### 3. 首次运行
- 程序会自动创建必要的目录和数据库
- 自动添加默认分类
- 自动扫描并导入data目录下的pb文件

## 🔧 使用说明

### 添加图片
1. 新建或编辑条目
2. 在右侧图片区域点击"选择图片"
3. 选择图片文件，程序会自动复制到附件目录
4. 图片会自动调整大小并显示

### 书籍信息
1. 选择分类为"书籍摘要"或相关分类
2. 填写书籍的详细信息
3. 所有信息都会保存到数据库

### 导出功能
1. **导出单个条目**：选中条目后点击"导出条目"
2. **导出所有条目**：点击"导出所有"
3. 选择导出格式（TXT/PDF）
4. 选择导出选项（元数据、图片等）
5. 选择保存位置

### 后端管理
1. **启动后端**：点击"启动后端"按钮或菜单
2. **停止后端**：点击"停止后端"按钮或菜单
3. **检查连接**：验证后端服务是否正常运行
4. **查看状态**：显示后端服务详细状态信息
5. **数据同步**：与后端API同步数据

## 📝 注意事项

1. **PDF导出**：需要安装reportlab库，如果不需要PDF功能可以不安装
2. **图片存储**：图片会自动复制到data/attachments目录，原文件不会被移动
3. **数据库升级**：程序会自动检测并升级数据库结构，无需手动操作
4. **文件编码**：所有文件都使用UTF-8编码，支持中文
5. **后端管理**：需要安装psutil库用于进程管理，requests库用于API通信
6. **Go后端**：确保../backend目录存在Go后端代码，或配置其他后端服务地址

## 🐛 常见问题

### Q: 图片无法显示？
A: 检查图片文件是否存在，确保PIL库已正确安装

### Q: PDF导出失败？
A: 确保已安装reportlab库：`pip install reportlab`

### Q: 数据库加载失败？
A: 检查data目录权限，程序会自动重新创建数据库

### Q: 中文显示乱码？
A: 确保系统支持中文，程序使用UTF-8编码

### Q: 后端管理功能无法使用？
A: 确保已安装psutil和requests库：`pip install psutil requests`

### Q: 无法连接到后端服务？
A: 检查Go后端是否正在运行，或检查API地址配置
